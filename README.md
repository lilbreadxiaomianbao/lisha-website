# Lisha Liang · Co-operators Insurance Advisor

Personal website for Lisha Liang, a licensed Co-operators insurance advisor serving all of Ontario, Canada.

## Stack

Single-file static website (`index.html`) — no build step.

- Pure HTML, inline CSS, inline JS
- Google Fonts (Playfair Display + Inter)
- Trilingual client service (English, Mandarin, Cantonese)
- Quad-lingual UI (EN / 中文 / 日本語 / 한국어)
- Full SEO: hreflang, JSON-LD (InsuranceAgency + Person + FAQPage), OG tags

## Deploy

Static file — deploys to any static host:

- Cloudflare Pages (recommended)
- Netlify
- Vercel
- GitHub Pages
